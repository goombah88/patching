SAPI is an API running on the Corp Ansible server sjc01-z0-vm-cxt-ansible-01. It allows server to "phone home" to trigger actions in ansible.

Guide used to create the basic API - https://medium.com/@thishantha17/build-a-simple-python-rest-api-with-apache2-gunicorn-and-flask-on-ubuntu-18-04-c9d47639139b



ENDPOINTS:

Currently there are 2 endpoints defined.

/status - servers use this endpoint during patching to report status updates. These status updates will feed the patching dashboard, allowing us to properly monitor how patching is going.
/casa - (a.k.a. CheckAndSetAdmins) when servers hit this endpoint it will download the UnixAdmins.txt master file


TECH STACK:

The API itself is a Flask app written in python.
Gunicorn is utilized to serve as the production-grade WSGI server
nginx is used as a reverse proxy for gunicorn
utilizes 2 docker images -
sapi (built from python:3 image) - runs gunicorn which in turn runs the Flask app (sapi.py)
sapi_nginx (nginx image)
Port - 8000
